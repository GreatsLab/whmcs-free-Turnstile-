Free Cloudflare Turnstile protection for login, registration, lost password, comments and WooCommerce. Protected by AuroxHost.

== Description ==

Aurox Turnstile adds Cloudflare's free, privacy-friendly Turnstile check to the WordPress forms bots love most.
Most visitors never see a puzzle.

Protects: login (wp-login.php and wp_login_form()), registration, lost password, comments,
WooCommerce My Account login and registration, and the classic WooCommerce checkout.

Built by Chimnadindu Great Chibueze, founder of AuroxHost — https://auroxhost.com

== Installation ==

1. Upload the `aurox-turnstile` folder to `/wp-content/plugins/`.
2. Activate the plugin.
3. Go to Settings → Aurox Turnstile and paste your Site Key and Secret Key from the Cloudflare dashboard.
